Sandbox [things I know about the web]

A few deliberately ugly demos. Each one is a bug I have shipped at least once.

01 / The ellipse problem

border-radius: 50% on a rectangle gives you an ellipse, because 50% is resolved against width and height separately. You wanted a pill. Use border-radius: 9999px, or calc(infinity * 1px) if you like to live dangerously.

02 / Nested radius padding 24px · outer 32px

If the inner corner uses the same radius as the outer, the corners look wrong. The inner radius should be outer − padding. Tick the box and watch it stop fighting you.

03 / 100vh is a lie on phones —
100vh
100dvh
100svh

On mobile the browser chrome comes and goes, and 100vh uses the biggest possible viewport. Use dvh for things that should follow the toolbar, svh for things that must never jump.

04 / Glass button [11 layers, 0 images]
Github

One anchor, eleven nested spans. The rim is a rotating rainbow gradient masked to a 1.5px ring with mask-composite: exclude. Two CSS variables, --mx and --my, carry the pointer position and every layer reads them. No canvas, no images.
